# Prévia — Escola Modelo Cristão

Demonstração de uma proposta de página única. Não é o site oficial da escola.

Capa com foto real, informações institucionais, atividades, materiais, depoimentos e contato. O formulário é demonstrativo e não envia mensagens. As imagens e os conteúdos têm origem no site público https://www.modelocristao.com.br/ e pertencem aos respectivos titulares.

O arquivo .nojekyll permite servir estes arquivos estáticos diretamente no GitHub Pages.
